# Story Structure Templates

Reference for generating stories from OC and world data. Use these as flexible guides, not rigid formulas.

## Short Story (1000–5000 words)

```
1. Opening Hook — Drop into a moment that shows the OC's voice immediately
2. Inciting Event — Something disrupts the OC's normal routine
3. Rising Action — The OC reacts; their personality traits drive choices
4. Climax — A pivotal moment that tests a core trait or belief
5. Resolution — The OC is changed (even slightly) by what happened
```

## Chapter / Episode (3000–8000 words)

```
1. Cold Open — A scene that establishes tone and hooks curiosity
2. Status Quo — Show the OC in their normal environment
3. Catalyst — The event that launches this chapter's arc
4. Exploration — The OC investigates/reacts; relationships come into play
5. Midpoint Twist — New information or a complication
6. Confrontation — The OC faces the central challenge of the chapter
7. Denouement — Fallout and setup for what comes next
```

## Novel Arc (multi-chapter)

```
1. Ordinary World — Establish OC baseline, key relationships, world rules
2. Call to Adventure — The inciting event of the whole story
3. Refusal / Hesitation — The OC's flaw or fear holds them back
4. Crossing the Threshold — Commitment to the journey
5. Trials & Allies — Tests that reveal character, relationship development
6. Darkest Moment — The OC fails or loses something vital
7. Transformation — The OC applies what they've learned
8. Climax — Final confrontation
9. Return / New Normal — The OC in their changed state
```

## Genre-Specific Beats

### Romance
- Meet-cute → Growing attraction → Obstacle/conflict → Separation/crisis → Grand gesture → Resolution

### Mystery / Investigation
- Crime discovered → Initial clues → Red herrings → Key discovery → Confrontation → Reveal

### Action / Adventure
- Mission setup → First battle → Complication → Major setback → Final stand → Victory (or pyrrhic)

### Slice of Life
- Ordinary moment → Small catalyst → Reflection/reaction → Quiet insight → Return to normal (with new understanding)

## Using OC Data in Stories

When generating a story, specifically draw from:

1. **Speaking style** — Dialogue should match the OC's catchphrases and tone
2. **MBTI-informed decisions** — Plot choices should feel authentic to the OC's cognitive stack
3. **Key experiences** — Reference or build upon the OC's history
4. **Relationships** — Other characters act according to their own profiles
5. **World rules** — Stay consistent with the established world setting
6. **Glossary terms** — Use special terminology naturally and correctly

## Tone & Style Guidelines

- Match the user's demonstrated preferences (formal vs. casual, descriptive vs. dialogue-heavy)
- Default to a natural Chinese prose style (适合中文网络文学的流畅叙述)
- When in doubt, ask the user: "What kind of feel do you want for this story?"
